# 潜水艦人狼

原子力潜水艦が舞台の、オンラインで遊べる人狼ゲームです。遊ぶ人はブラウザだけで参加できます。

## 中身

- `server.js` … ゲームサーバー(Node.js。追加パッケージのインストールは不要です)
- `index.html` … ゲーム本体(ブラウザに表示される画面)
- `package.json` … 起動用の設定

## 自分のパソコンで動かす

1. Node.js 18 以上をインストールします。
2. このフォルダで `node server.js` を実行します(`npm start` でも同じです)。
3. ブラウザで http://localhost:3000 を開きます。
4. 同じWi-Fiにつないだ別の端末からは、`http://(パソコンのIPアドレス):3000` を開きます。

## インターネットに公開する

WebSocket が使える「Node.js を動かせるサービス」が必要です(例: Render、Railway、Fly.io、自分の VPS など)。
GitHub Pages、Netlify、Vercel のような静的ホスティングだけでは、サーバーを常に動かせないので使えません。

例: Render の場合

1. このフォルダを GitHub のリポジトリにアップロードします。
2. Render で「New → Web Service」を選び、そのリポジトリを指定します。
3. Start Command に `node server.js` を指定してデプロイします(Build Command は空欄か `npm install` で構いません)。
4. 発行された URL(`https://〜`)を開くと遊べます。HTTPS のときは自動で `wss://` で接続します。

VPS で nginx を使う場合は、`/ws` を WebSocket 対応のプロキシとして node に渡してください(`Upgrade` と `Connection` のヘッダーを転送する設定が必要です)。

## 設定

- `PORT` … 待ち受けるポート番号(環境変数。省略すると 3000)
- `ALLOWED_ORIGIN` … 指定すると、そのオリジンからの接続だけを許可します(例: `https://example.com`)
- 1ルームの最大接続数などの上限は、`server.js` の冒頭にあります。

## 注意

- ルームはサーバーのメモリ上にあるだけです。サーバーを再起動するとすべて消えます。
- 無料プランのサービスは、しばらくアクセスがないと止まり、次のアクセスで起動に時間がかかることがあります。
- ルームIDを知っている人は誰でも入室できます。ログインやパスワードはありません。
- 役職や投票の情報は、ゲームを動かす通信に含まれています。ブラウザの開発者ツールを使うと見えてしまうため、仲間内で遊ぶ前提です。
- 回線が一時的に切れても、約1分以内なら自動で復帰します。切れていた間のイベントも再送されます。ホストの回線が切れた場合も同じです。
